# To-Do List App

A simple to-do list application built with the MERN stack.

## Tech Stack

- **M**ongoDB
- **E**xpress
- **R**eact
- **N**ode.js

## Getting Started

1. Fork this repository, then clone your fork:

   ```bash
   git clone https://github.com/<your-username>/<repo-name>.git
   ```
2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```
4. Open `http://localhost:3000` in your browser for the server.

## Requirements:

- Node.js (v18+)
- MongoDB running locally or a MongoDB Atlas connection string
